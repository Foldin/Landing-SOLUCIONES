# Landing Soluciones

Esta es una implementación básica de la landing mostrada en Figma. El proyecto se compone de HTML y CSS puros.

## Estructura

- `index.html` – página principal de la landing.
- `css/styles.css` – hoja de estilos.
- `assets/` – carpeta para las imágenes exportadas desde Figma (actualmente con marcadores de posición).

Para ver el sitio simplemente abre `index.html` en tu navegador.
